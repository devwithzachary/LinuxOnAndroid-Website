Privacy Policy

Effective Date: August 4, 2026

Complete Linux Installer (Linux on Android) is an open-source application dedicated to respecting user privacy. This Privacy Policy outlines our commitment to user confidentiality and data security.

1. Zero Data Collection

Complete Linux Installer does not collect, store, track, transmit, or monetize any personal data, device identifiers, IP addresses, usage analytics, or telemetry. All operation occurs 100% locally on your device inside your app private sandbox.

2. Network Access & Package Mirrors

The application requests network access (android.permission.INTERNET) solely for downloading official Linux rootfs tarballs and software package updates directly from official distribution mirrors (Ubuntu, Debian, Fedora, Alpine, Arch Linux, Kali, and Void Linux). No personal telemetry, device identifiers, or usage data are ever sent to developer servers.

3. Device Storage Access

Storage permissions (READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE) are requested exclusively to bind your device's shared storage (/sdcard) into the guest Linux filesystem when enabled by the user.

4. Open Source Transparency

Complete Linux Installer is licensed under the GNU General Public License v2.0 (GPL-2.0). The complete source code is publicly inspectable on GitHub.

5. Contact & Questions

If you have any questions regarding this Privacy Policy, please visit our GitHub Repository to open an issue.
